# КАГУНЕ — мини-сериал про гулей

Оригинальная история в трёх эпизодах (+ тизер второго сезона). Рассказ от первого лица: ты — Кай, студент, которого превратили в гуля с четырьмя алыми щупальцами-кагуне.

| Эпизод | Название | О чём |
|---|---|---|
| 1 | **Пробуждение** | Нападение в переулке, больница, чужой глаз в зеркале, убежище «Тишина», первое пробуждение кагуне в бою с охотником Варгом |
| 2 | **Голод** | Тренировки, виды кагуне, прошлое Миры, сожжённое убежище, срыв в голод и появление Короля Масок |
| 3 | **Алая луна** | Союз с охотником, Башня «Кацура», лаборатории, финальный бой на крыше, тизер «Тысяча масок» |

Персонажи: **Кай** (ты), **Мира** — гуль с кристаллическими крыльями, **Ржавый** — старик, хранитель убежища, **Варг** — охотник с клинком из кагуне, **Король Масок** — учёный, который делает гулей из людей.

## Как устроено

Всё сгенерировано кодом, без готовых картинок и сэмплов:

| Файл | Что делает |
|---|---|
| `story.py` | Сценарий: кадры, реплики, звуки |
| `tts.py` | Озвучка нейросетевыми голосами Piper (ru_RU: ruslan, irina, dmitri, denis) + обработка ffmpeg: питч, хор, эхо под каждого персонажа. Пишет `timeline.json` с таймингом и огибающей голоса для движения губ |
| `sound.py` | Синтез звуков (дождь, сердцебиение, удары, щупальца, вороны, тревога), музыки (тёмный пэд, боевые барабаны), сведение с приглушением под голос |
| `scene.html` | ~30 анимированных сцен на Canvas 2D |
| `render.mjs` | Рендер кадров в headless Chromium (Playwright) прямо в ffmpeg, параллельно |

## Сборка

```bash
pip install piper-tts numpy scipy
# голоса: https://github.com/k2-fsa/sherpa-onnx/releases/tag/tts-models
#   vits-piper-ru_RU-{ruslan,irina,dmitri,denis}-medium.tar.bz2 -> распаковать в VOICES
python3 tts.py VOICES out
for e in 1 2 3; do python3 sound.py out $e; node render.mjs out $e --workers=4; done
# готово: out/epN/kagune_epN.mp4
```

Превью отдельных кадров: `node render.mjs out 1 --preview=10,42.5,90`.
